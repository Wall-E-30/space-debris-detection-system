<task id="01-03-02" type="implementation">
  <read_first>
    - edge/benchmark.py
    - edge/export.py
  </read_first>
  <action>
    Implement D-05 and D-06 by refactoring `edge/benchmark.py` to upgrade the measurement protocol to research-grade standards:
    1. Enforce minimum parameters (D-05):
       - `--runs`: Default 100 (timed iterations)
       - `--warmup`: Default 10 (warm-up runs before timing)
       - `--threads`: Default 4 (fixed CPU threads for Pi 4 Cortex-A72 cores)
       - `--imgsz`: Default 640 (int)
       - `--out`: Destination JSON path (default: 'edge_benchmark.json')
    2. In `benchmark_onnx`:
       - Configure `SessionOptions.intra_op_num_threads = threads` and `inter_op_num_threads = 1`.
       - Run 10 warmup iterations.
       - Measure wall-clock latency per iteration using `time.perf_counter()`.
       - Track whole-process peak Resident Set Size (`process.memory_info().rss / (1024 * 1024)`) in MB via `psutil.Process(os.getpid())`.
       - Compute statistics: `mean_ms`, `median_ms`, `p95_ms`, `min_ms`, `max_ms`, `std_ms`, `fps`, and `peak_rss_mb`.
    3. In `benchmark_ncnn`:
       - Set `net.opt.num_threads = threads`.
       - Run 10 warmup iterations.
       - Measure latencies and peak RSS identical to the ONNX procedure.
    4. Save full benchmarking results adhering to the D-06 JSON schema (`edge_benchmark.json`) with hardware info (`platform.machine()`, `platform.processor()`, timestamp, threads, model path).
  </action>
  <acceptance_criteria>
    - `edge/benchmark.py` includes `--warmup`, `--runs`, `--threads`, and `--out` CLI arguments.
    - Script measures peak RSS in MB using `psutil.Process(os.getpid()).memory_info().rss`.
    - Script writes standardized results dictionary to `--out` JSON file when executed.
  </acceptance_criteria>
  <verify>
    <automated>python edge/benchmark.py --help</automated>
    <fails_when>non-zero exit code or "error" in stdout/stderr</fails_when>
  </verify>
</task>
