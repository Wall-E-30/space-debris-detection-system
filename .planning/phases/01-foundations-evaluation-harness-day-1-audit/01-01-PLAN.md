# Plan 01-01: Standalone Evaluation Harness & SwissCube Baseline Reproduction

<objective>
Implement the standalone evaluation CLI `src/eval.py` that wraps Ultralytics `YOLO.val()` and produces a standardized `metrics.json` artifact containing bounding box mAP, class metrics, model parameters, FLOPs, and disk footprint. Verify this harness by evaluating the existing Week 1 SwissCube baseline checkpoint (`experiments/week1_smoke_test/weights/best.pt`), confirming reproduction of the documented baseline metrics (mAP@0.5 ≈ 0.9903, mAP@0.5:0.95 ≈ 0.9211).
</objective>

<tasks>

<task id="01-01-01" type="implementation">
  <read_first>
    - src/eval.py
    - experiments/week1_smoke_test/args.yaml
    - experiments/week1_smoke_test/results.csv
    - spark.yaml
  </read_first>
  <action>
    Implement `src/eval.py` as an independent CLI tool using `argparse` and `ultralytics.YOLO`.
    The script must support the following CLI arguments:
    - `--weights`: Path to model weights file (.pt or exported format)
    - `--data`: Path to dataset configuration YAML
    - `--split`: Evaluation split name (default: 'val', choices: ['val', 'test', 'train'])
    - `--imgsz`: Input image resolution (int, default: 1024)
    - `--batch`: Batch size for evaluation (int, default: 8)
    - `--device`: Target compute device (default: '0' or 'cpu')
    - `--out`: Destination file path for the output JSON (default: 'metrics.json')

    The script loads `YOLO(weights)` and calls `model.val(data=..., split=..., imgsz=..., batch=..., device=..., plots=False)`.
    Extract metrics from the returned `results.box` object:
    - `map50`: float(results.box.map50)
    - `map50_95`: float(results.box.map)
    - `mp`: float(results.box.mp) (mean precision)
    - `mr`: float(results.box.mr) (mean recall)
    - `inference_time_ms`: float(results.speed['inference'])
    - `preprocess_time_ms`: float(results.speed['preprocess'])
    - `postprocess_time_ms`: float(results.speed['postprocess'])
    - `per_class`: dict mapping class index/name to `{'p': float, 'r': float, 'map50': float, 'map50_95': float}` using `results.box.p`, `results.box.r`, `results.box.ap50`, and `results.box.ap`
    - `size_mb`: round(weights_path.stat().st_size / (1024 * 1024), 2)
    - `params`: int (from `model.info(verbose=False)[1]` if weights end with .pt)
    - `gflops`: float (from `model.info(verbose=False)[3]` if weights end with .pt)
    - `timestamp`: ISO-8601 formatted string
    - `model_path`: str(weights)
    - `data_path`: str(data)
    - `imgsz`: imgsz
    - `split`: split

    Write formatted JSON to the path specified by `--out` with indent=2.
  </action>
  <acceptance_criteria>
    - `src/eval.py` exists and is non-empty.
    - `python src/eval.py --help` exits with code 0 and displays `--weights`, `--data`, `--split`, `--imgsz`, and `--out` options.
    - Script defines function `evaluate_model(weights, data, split, imgsz, batch, device, out_json)`.
  </acceptance_criteria>
  <verify>
    <automated>python src/eval.py --help</automated>
    <fails_when>non-zero exit code or "error" in stdout/stderr</fails_when>
  </verify>
</task>
