# Plan 01-02: Day-1 SPARK Annotation Audit & Debris Taxonomy Resolution

<objective>
Inspect the full raw SPARK dataset CSV annotations (`data/raw/spark/train.csv` and `data/raw/spark/val.csv`) to resolve Finding F1, Decision D-01, and Decision D-02 (DEC-04). Verify whether any annotated instances of space debris exist in the raw annotations, compute class distribution frequencies, and document the final dataset taxonomy decision in `docs/decisions.md`.
</objective>

<task id="01-02-01" type="implementation">
  <read_first>
    - data/raw/spark/train.csv
    - data/raw/spark/val.csv
    - docs/decisions.md
    - data/decisions.md
  </read_first>
  <action>
    Implement D-01 by creating `scripts/audit_spark_annotations.py` to parse CSV annotation files from the SPARK dataset without assuming class names in advance.
    The script must:
    - Accept `--train_csv` (default: 'data/raw/spark/train.csv') and `--val_csv` (default: 'data/raw/spark/val.csv') CLI arguments.
    - Accept `--out` (default: 'docs/spark_class_audit.json') to save structured audit results.
    - Read each CSV row using standard library `csv.DictReader`.
    - Count total rows, total unique images, and frequencies for every unique entry in the `Class` column across both train and val splits.
    - Check case-insensitively for the presence of 'debris', 'fragment', 'debris_small', or 'rocket_body' in class names.
    - Compute total count of debris instances versus satellite/spacecraft instances.
    - Output a human-readable summary table to stdout and write JSON results to `--out`.
  </action>
  <acceptance_criteria>
    - `scripts/audit_spark_annotations.py` exists and is executable via Python.
    - Running `python scripts/audit_spark_annotations.py --help` exits with code 0 and lists arguments.
    - Script handles CSV headers `Image name,Mask name,Class,Bounding box` robustly.
  </acceptance_criteria>
  <verify>
    <automated>python scripts/audit_spark_annotations.py --help</automated>
    <fails_when>non-zero exit code or "error" in stdout/stderr</fails_when>
  </verify>
