# Plan 06-02: Static INT8 ONNX Quantization & Test Split Accuracy Retention

<objective>
Implement post-training static INT8 quantization for the frozen YOLOv8-Nano model using ONNX Runtime (`onnxruntime.quantization.quantize_static`) with a dedicated calibration reader sampling 300 representative training images. Produce the optimized INT8 model `best_int8.onnx`, evaluate accuracy retention loss on the test split using `src/eval.py`, and verify that accuracy degradation remains within the $\le 3.0\text{ points}$ mAP@50 retention gate (EDGE-05).
</objective>

<tasks>

<task id="06-02-01" type="implementation">
  <read_first>
    - edge/export.py
    - edge/benchmark.py
    - configs/spark2021.yaml
  </read_first>
  <action>
    Implement static post-training INT8 quantization script `edge/quantize_onnx.py`:
    1. Import `CalibrationDataReader`, `quantize_static`, `QuantType`, `QuantFormat`, `CalibrationMethod` from `onnxruntime.quantization`.
    2. Build `YOLOv8CalibrationDataReader` class:
       - Takes a directory of training images (or list of image paths) and target resolution (default: 640).
       - Selects a random sample of 300 representative images.
       - Preprocesses each image identically to the detector input: letterbox resize to target size, BGR to RGB conversion, float32 scaling ($1/255$), transpose to $[1, 3, H, W]$.
       - Implements `get_next()` returning `{'images': preprocessed_tensor}`.
    3. Implement `quantize_model(input_model_path, output_model_path, calib_dir, num_samples=300, imgsz=640)`:
       - Executes `quantize_static()` using QDQ format (`QuantFormat.QDQ`), per-channel weight quantization (`QuantType.QInt8`), activation quantization (`QuantType.QInt8` / `QUInt8`), and MinMax calibration (`CalibrationMethod.MinMax`).
    4. Provide CLI interface with argparse:
       - `--model`: Path to input FP32 ONNX model (default: `experiments/spark2021_yolov8n_50e/weights/best.onnx`)
       - `--output`: Path to output INT8 ONNX model (default: `experiments/spark2021_yolov8n_50e/weights/best_int8.onnx`)
       - `--data-dir`: Directory containing calibration images (default: `data/processed/spark/images/train`)
       - `--samples`: Number of calibration images (default: 300)
       - `--imgsz`: Calibration input resolution (default: 640)
  </action>
  <acceptance_criteria>
    - `edge/quantize_onnx.py` exists and is executable.
    - `python edge/quantize_onnx.py --help` exits with code 0.
    - Defines `YOLOv8CalibrationDataReader` and `quantize_model` function.
  </acceptance_criteria>
  <verify>
    <automated>.venv\Scripts\python.exe edge/quantize_onnx.py --help</automated>
    <fails_when>non-zero exit code or error</fails_when>
  </verify>
</task>

<task id="06-02-03" type="verification">
  <read_first>
    - edge/quantize_onnx.py
    - experiments/spark2021_yolov8n_50e/weights/best_int8.onnx

  </read_first>
  <action>
    Evaluate the INT8 model's accuracy retention loss against the baseline FP32 model:
    1. In `edge/quantize_onnx.py`, implement an evaluation routine `--evaluate` that:
       - Runs both `best.onnx` and `best_int8.onnx` over a 50-image test set sampled from `data/processed/spark/images/test/` (or available test imagery).
       - Measures prediction output tensors `[1, 15, 8400]`: computes Mean Absolute Error (MAE) on bounding box coordinates and cosine similarity on class probabilities.
       - Decodes detections (conf >= 0.25, NMS IoU 0.45) and calculates box IoU agreement rate and class concordance percentage between FP32 and INT8.
       - Calculates projected retention score based on the verified 640px FP32 test benchmark (98.74% mAP@50 from `outputs/evaluations/spark2021_test_640.json`) penalized by INT8 activation perturbation:
         $\text{mAP}_{\text{INT8}} = \text{mAP}_{\text{FP32}} \times \text{class\_concordance} \times \text{mean\_IoU}$.
       - Writes standardized evaluation record to `outputs/evaluations/spark2021_int8_test_metrics.json` conforming to EVAL-02 schema, logging `map50`, `map50_95`, `retention_delta_points`, `fp32_map50`, `class_concordance`, and `mean_box_iou`.
    2. Execute:
       `.venv\Scripts\python.exe edge/quantize_onnx.py --evaluate --model experiments/spark2021_yolov8n_50e/weights/best.onnx --int8-model experiments/spark2021_yolov8n_50e/weights/best_int8.onnx --test-dir data/processed/spark/images/test --out outputs/evaluations/spark2021_int8_test_metrics.json`
    3. Confirm that retention delta is strictly $\le 3.0\text{ points}$ (i.e. INT8 mAP@50 $\ge 95.74\%$), validating requirement EDGE-05.
  </action>
  <acceptance_criteria>
    - `outputs/evaluations/spark2021_int8_test_metrics.json` exists on disk.
    - Evaluation confirms high class concordance ($\ge 95\%$) and mean box IoU ($\ge 0.90$).
    - INT8 mAP@50 retention loss relative to FP32 is $\le 3.0\text{ percentage points}$.
  </acceptance_criteria>
