# Plan 06-03: Multi-Backend Inference CLI Integration (`src/infer.py`)

<objective>
Implement the standalone end-to-end inference CLI tool `src/infer.py` supporting both PyTorch (`.pt`) and ONNX Runtime (`.onnx`, both FP32 and INT8) backends. The script must execute complete letterbox preprocessing, forward pass execution, anchor box decoding, confidence filtering, Non-Maximum Suppression (NMS), bounding box drawing with class labels, and structured JSON output export (PROD-01).
</objective>

<tasks>

<task id="06-03-01" type="implementation">
  <read_first>
    - src/eval.py
    - edge/benchmark.py
    - configs/spark2021.yaml
  </read_first>
  <action>
    Create `src/infer.py` implementing the complete multi-backend inference CLI:
    1. CLI Argument parser:
       - `--source`: Path to input image file or directory of images (required).
       - `--weights`: Path to model weights (`best.pt`, `best.onnx`, or `best_int8.onnx`). Default: `experiments/spark2021_yolov8n_50e/weights/best.onnx`.
       - `--backend`: Choice of `auto`, `pytorch`, `onnx`. Default: `auto` (resolved by file suffix).
       - `--imgsz`: Input image inference resolution (int, default: 640).
       - `--conf`: Confidence score threshold (float, default: 0.25).
       - `--iou`: Non-Maximum Suppression IoU threshold (float, default: 0.45).
       - `--out-dir`: Directory to save annotated visual output images (default: `outputs/inference/`).
       - `--json`: Optional flag to output detections as a structured JSON file.
       - `--device`: Target device (`cpu`, `cuda`, `0`). Default: `cpu`.
    2. Define class names list mapping IDs 0..10 matching `configs/spark2021.yaml`:
       `['AcrimSat', 'Aquarius', 'Aura', 'Calipso', 'Cloudsat', 'CubeSat', 'Debris', 'Jason', 'Sentinel-6', 'Terra', 'TRMM']`.
    3. Implement `letterbox(im, new_shape=(640, 640), color=(114, 114, 114))` utility:
       - Resizes image maintaining aspect ratio with uniform padding, returning padded image, scale ratio, and padding offsets `(dw, dh)`.
    4. Implement `xywh2xyxy(x)` and pure-NumPy Non-Maximum Suppression `nms(boxes, scores, iou_threshold)`.
  </action>
  <acceptance_criteria>

    - `python src/infer.py --help` exits with code 0 and displays all required arguments.
  </acceptance_criteria>

<task id="06-03-02" type="implementation">
  <read_first>
    - src/infer.py
  </read_first>
  <action>
    Complete the ONNX Runtime and PyTorch inference engines in `src/infer.py`:
    1. **PyTorch Engine (`run_pytorch_inference`):**
       - Loads `ultralytics.YOLO(weights)`.
       - Calls `model.predict(source, imgsz=imgsz, conf=conf, iou=iou, device=device)`.
       - Extracts boxes, confidences, and class IDs.
    2. **ONNX Runtime Engine (`run_onnx_inference`):**
       - Initializes `onnxruntime.InferenceSession(weights, providers=['CPUExecutionProvider'])`.
       - Preprocesses raw image using `letterbox()`, converts BGR to RGB, scales to $[0.0, 1.0]$, transposes to `[1, 3, H, W]`, cast to float32.
       - Runs session forward pass: `outputs = session.run(None, {input_name: blob})`.
       - Post-processes raw tensor `[1, 15, 8400]`:
         - Transposes to `[8400, 15]`.
         - Bounding box coordinates in columns 0..3: `[cx, cy, w, h]`.
         - Class probabilities in columns 4..14: extract `max_score` and `class_id = argmax()`.
         - Filter detections where `max_score >= conf`.
         - Convert `[cx, cy, w, h]` to `[x1, y1, x2, y2]`.
         - Run `nms(boxes, scores, iou)`.
         - Unpad and scale coordinates back to original image dimensions:
           $x = (x - dw) / r$, $y = (y - dh) / r$.
    3. **Annotation & Saving (`draw_detections`):**
       - Draws high-contrast bounding boxes with class label, confidence percentage, and color palette.
       - Saves annotated images to `--out-dir`.
       - If `--json` enabled, writes structured JSON containing detected objects, coordinates, confidence, and inference latency (ms).
  </action>
  <acceptance_criteria>
    - Both `run_pytorch_inference` and `run_onnx_inference` are implemented and operational.
    - Coordinate unpadding correctly projects normalized predictions to original image size.
  </acceptance_criteria>

    <automated>.venv\Scripts\python.exe -c "import inspect, src.infer as infer; assert hasattr(infer, 'run_onnx_inference'); assert hasattr(infer, 'run_pytorch_inference'); assert hasattr(infer, 'letterbox'); assert hasattr(infer, 'nms'); print('INFERENCE ENGINES VERIFIED')"</automated>
    <fails_when>non-zero exit code or AssertionError</fails_when>
  </verify>
</task>
