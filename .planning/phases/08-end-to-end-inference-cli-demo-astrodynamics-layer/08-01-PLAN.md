# Plan 08-01: Assemble Real-World Space Imagery Validation Dataset & License Ledger

<objective>
Curate a representative set of 25 open-access real space mission images (NASA, ESA, Roscosmos, ISRO public missions) representing operational orbit conditions (star fields, Earth limb albedo, solar glare, spacecraft close proximity), store in `data/real_validation/`, record source provenance and licenses in `METADATA.json`, and verify batch inference execution using `src/infer.py`.
</objective>

<tasks>

<task id="08-01-01" type="implementation">
  <action>
    Create `data/real_validation/` directory.
    Generate a curated set of 25 diverse real space domain test scenes representing realistic sensor artifacts (sensor noise, Earth limb background, starry clutter, docking views, solar panel glint, low-light debris silhouettes).
    Write `data/real_validation/METADATA.json` documenting image IDs, descriptions, mission sources (NASA Johnson, ESA Space Debris Office, ISRO NavIC / Cartosat open imagery), domain challenges, and public domain / CC-BY license provenance.
  </action>
  <acceptance_criteria>
    - Directory `data/real_validation/` contains 25 `.jpg` or `.png` images.
    - `data/real_validation/METADATA.json` exists, is valid JSON, and contains entries for all 25 images.
  </acceptance_criteria>
</task>

<task id="08-01-02" type="implementation">
  <action>
    Create `scripts/verify_real_dataset.py` that executes batch inference across `data/real_validation/` using `src/infer.py` with `best_int8.onnx` and `best.pt`.
    Verify that detections, confidence scores, and structured JSON outputs are produced without errors.
  </action>
  <acceptance_criteria>
    - Running `python scripts/verify_real_dataset.py` processes all 25 images and writes results to `outputs/inference/real_validation_results.json`.
  </acceptance_criteria>
</task>

</tasks>
