# Plan 08-02: Interactive Demonstration Application & Decoupled Astrodynamics Panel

<objective>
Develop an interactive demonstration application (`demo/app.py`) providing a real-time web UI for space object detection. Users can upload space images or select preloaded test scenes, adjust confidence and IoU thresholds, choose inference engine (ONNX Static INT8, ONNX FP32, PyTorch FP16), view real-time latency and memory telemetry, and query the decoupled SGP4 orbital tracking panel (DEC-05) for cataloged assets.
</objective>

<tasks>

<task id="08-02-01" type="implementation">
  <action>
    Build `demo/app.py` using Python's standard library `http.server` (or lightweight web server requiring zero heavy external dependencies like gradio/streamlit) with a modern responsive UI:
    1. Interactive image upload / preset selector (SwissCube, SPARK-2021, and Real Space scenes).
    2. Controls for confidence threshold, IoU threshold, and model runtime selection (`best_int8.onnx`, `best.onnx`, `best.pt`).
    3. Live annotated image canvas with bounding boxes and class tags.
    4. Real-time Telemetry HUD: Inference Latency (ms), Throughput (FPS), Model Binary Size (MB), Peak Memory RSS.
    5. Independent SGP4 Astrodynamics Panel querying `src/data/tle_pipeline.py`:
       - If a cataloged satellite (e.g. Sentinel-6, Terra, Calipso) is detected: displays NORAD ID, epoch timestamp, and 3D ECI orbital coordinates ($X, Y, Z$ in km).
       - If debris or a CubeSat is detected: displays physical honesty disclaimer ("Uncataloged: 2D bounding boxes cannot infer 3D orbits without multi-station radar/optical tracklets").
    6. Support headless API mode (`POST /api/infer`) and browser UI (`GET /`).
  </action>
  <acceptance_criteria>
    - `demo/app.py` exists and can be imported and executed.
    - `POST /api/infer` accepts image data and returns bounding boxes, latency, model footprint, and orbital state info.
  </acceptance_criteria>
</task>

<task id="08-02-02" type="implementation">
  <action>
    Create automated unit tests in `tests/test_demo_app.py` testing the demo application backend:
    - Test health endpoint / web handler.
    - Test inference API with synthetic image input.
    - Test astrodynamics response integration.
  </action>
  <acceptance_criteria>
    - `pytest tests/test_demo_app.py` passes with 100% pass rate.
  </acceptance_criteria>
</task>

</tasks>
