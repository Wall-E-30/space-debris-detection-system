</objective>

    - Exactly 12,500 instances for each of the 10 satellite classes.
    - JSON artifact created at `docs/spark2021_class_audit.json`.

  <acceptance_criteria>

<task id="02-01-03" type="implementation">
  <read_first>
    - scripts/convert_spark2021_to_yolo.py
    - configs/spark2021.yaml
  </read_first>
  <action>
    Implement `scripts/convert_spark2021_to_yolo.py` to convert SPARK-2021 coordinates to normalized YOLO format:
    1. Perform coordinate swap:
       - $cx = ((c_{\min} + c_{\max}) / 2.0) / W$
       - $cy = ((r_{\min} + r_{\max}) / 2.0) / H$
       - $w = (c_{\max} - c_{\min}) / W$
       - $h = (r_{\max} - r_{\min}) / H$
    2. Map class labels to IDs 0–10.
    3. Generate collision-free names `{class_name}_{image_stem}` in `data/processed/spark2021/{images,labels}/{train,val,test}/`.
    4. Support `--link-mode copy|hardlink|symlink` and `--labels-only`.
    5. Support visual verification sample overlays via `--verify-samples`.
    6. Provide dataset configuration in `configs/spark2021.yaml`.
  </action>
  <verify>
    Verify `configs/spark2021.yaml` exists and defines all 11 classes:
    ```yaml
    names:
      0: AcrimSat
      1: Aquarius
      2: Aura
      3: Calipso
      4: Cloudsat
      5: CubeSat
      6: Debris
      7: Jason
      8: Sentinel-6
      9: Terra
      10: TRMM
    ```
    Verify `scripts/convert_spark2021_to_yolo.py --help` executes cleanly.
  </verify>
  <acceptance_criteria>
    - Bounding box conversion correctly transforms row/column inputs to normalized YOLO format.
    - `configs/spark2021.yaml` correctly specifies paths and all 11 class names.
  </acceptance_criteria>
</task>
